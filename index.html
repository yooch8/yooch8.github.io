감염병 분자진단 기업 씨젠의 SW연구소에서, 진단 시약 연구원이 쓰는 유전자 설계 · 분석 소프트웨어를 운영하고 기획합니다.

씨젠 ① · 2022.01 – 2026.10

사내 in-silico 설계 · 분석 플랫폼 클라우드 전환 · 런칭

PO (2022 – 2025)팀장 (2024 – )프로젝트 총괄 (2025.11 – )48명 · 3개 팀 협업
질문

연구원이 더 편하게 쓰고, 더 빨리 결과를 받고, 회사는 합리적인 비용으로 운영하는 플랫폼을 어떻게 만들 것인가

어떤 서비스인가

PCR 진단키트의 성능은 특정 병원체에만 달라붙는 짧은 DNA 조각(올리고)을 얼마나 잘 설계하느냐에 달려 있습니다. 열쇠(올리고)가 모든 변이 자물쇠(병원체)에는 맞고, 다른 자물쇠에는 맞지 않아야 합니다. 이 설계와 검증을 실험 전에 컴퓨터로 시뮬레이션하는 것을 in-silico 라고 부릅니다.

연구원이 웹에서 작업을 요청하면 서버가 수천만 건의 유전체 데이터를 대상으로 수 분에서 수십 시간짜리 분석을 돌려 결과를 돌려줍니다. 연구원 200여 명이 연간 1만 건 이상 사용합니다.

설계

병원체 정보를 넣으면 올리고 후보를 자동 설계 · 여러 병원체를 한 번에 검사하는 멀티플렉스 조합 비교 · 웹에서 결과를 고치고 바로 재실행

분석 5종

설계한 올리고가 변이주를 빠짐없이 잡는지(커버리지), 서로 간섭하지 않는지(다이머) 등을 검증 · 결과를 웹에서 바로 확인

편의 도구

녹는 온도 계산 · 위치 보기 · 서열 변환 등 요청 없이 웹에서 즉시 쓰는 도구 · 신기술 계산 기능 선적용

문제 — 연구원이 겪던 불편

쓰기 불편

PC 설치형이라 설치 오류가 잦고, 결과를 보려면 운영자에게 대행을 요청해야 했습니다.

오래 기다림

한 번에 돌릴 수 있는 작업 수에 한계가 있고, 무거운 분석은 하룻밤을 넘겨 18시간이 걸렸습니다.

  • 사용자 설문 · 기획 피드백을 더해, 계획한 요구사항 102건에 55건을 추가해 1차 요구사항 143건 확정 · 기존 시스템 개선 요청 43건 중 38건 반영

  • 운영자 대행 없이 연구원이 웹에서 직접 요청 · 진행 상황 확인 · 결과 수정 · 재실행까지 하도록 흐름 설계

② 대기 시간 — 알고리즘과 인프라

  • 핵심 알고리즘 개선 · 개발팀과 함께 분석 단계별 병목을 찾아 개선 — 대형 분석의 통계 단계 약 2시간 26분 → 4분, 서열 검색 조건 조정으로 실행 시간 중앙값 75% 단축
  • 인프라 테스트 · 운영 서버에서 동시 실행 한계 · 모듈 간 자원 경합 · 작업 크기별 소요 시간과 단가를 실측해 서버 구성 확정 — 대형 분석 1건이 서버 1대를 차지하는 구조를 찾아 동시 실행 상한을 정함
  • 무거운 단계 분리 · 서열 추출 서비스를 필요할 때만 서버를 띄우는 방식으로 바꿔 처리 시간 6시간 41분 → 약 13분

③ 비용 — 쓴 만큼만 내는 구조로

  • 쓰지 않을 때도 켜 두던 고성능 디스크를 없애고 원본 저장소를 바로 읽도록 바꿔 고정 디스크 비용 사실상 제거 (피크 메모리 90% 감소)
  • 서열 검색 서버를 과금 없는 전용 경로 · 저가 노드로 옮겨 노드 시간 단가 73% · 월 비용 62% 절감
  • 같은 작업량 · 같은 범위로 맞춰 비교했을 때 운영비가 기존 설치형보다 낮아짐 — 같은 서버를 2026년 시세로 다시 사는 경우와 비교하면 차이는 더 커짐

④ 검증 — 런칭 여부는 결과로

기능 → 통합 2단계 QA 구조를 정의하고, 런칭 전에는 단계마다 합격 기준을 먼저 정한 5단계 검증을 설계했습니다. 참여 인력이 30% 줄었을 때는 범위를 줄이는 대신 AI 도구 도입 · QA 외주 분리 · 모듈 순서 재배치로 계획을 바꿔 일정을 지켰습니다.

프로지니어(주) · 2020.01 – 2020.06 · 과장

핵산 구조 기반 신규 진단기술 PoC — 암 바이오마커 검출

질문

PCR 없이 DNA 나노구조와 형광 신호만으로 암을 찾아낼 수 있는가

혈액이나 조직 속 암 바이오마커(miRNA, 간암 · 대장암)를 PCR 증폭 없이 DNA 나노구조와 형광 신호만으로 검출하는 신규 진단기술의 개념 검증(PoC)을 맡았습니다.

  • 검출 성능 시험 — 얼마나 적은 양까지 잡는지(민감도), 다른 유전자에 반응하지 않는지(특이도) 시험 · 반응 온도 · 버퍼 조건 최적화
  • 실제 환자 검체 적용 — 혈장 · 조직 검체를 상용 PCR 키트 결과와 비교
  • 판단 — 최적화한 조건에서도 민감도가 임상 적용 기준에 못 미친다고 결론. 신호를 증폭하는 대안 컨셉 2종(bDNA · Hybrid Capture)을 설계하고 재료를 조사
가져간 것

가설 → 실험 → 데이터로 Go/No-Go를 판단하는 방식. 그리고 진단 결과를 좌우하는 것이 시약만이 아니라는 확신 → SW 기획으로 커리어 전환.

롤링스톤(주) · 2018.07 – 2019.08 · 프리랜서

수입 의존 진단 핵심 원료의 자체 생산 기술 개발

질문

비싸고 오래 걸리는 수입 원료를 우리가 직접 만들 수 있는가

HIV · C형 간염 등 고위험 바이러스 진단키트에는 "몇 copy가 들어 있는지" 기준이 되는 정량 표준물질이 필요합니다. 그 원료(Armored RNA — 바이러스 껍질로 RNA를 감싸 안정화한 물질)를 자체 생산하는 기술을 개발한 산학 프로젝트입니다.

배경

글로벌 진단기업들이 쓰는 수입 원료는 1억 copies/ml 기준 약 $15,000에 발주 6 ~ 8주. 원천 특허가 만료된 점을 활용해 내재화하면 키트 원가를 낮출 수 있다고 판단.

수행
  • 생산용 유전자 클론 설계 · 제작
  • 대장균 발현 · 세포 파쇄 · 정제 조건 확립
  • 가속 노화 기반 보관 안정성 시험
  • real-time PCR 기반 정량 측정법 수립

결과

  • HIV · C형 간염 등 4종 생산 클론과 제작 SOP(최종보고서) 납품
